# AI 協作揭露

## 使用者提供的需求
課程要求設計小專案、建立 AGENTS.md 或 CLAUDE.md、完成網頁、上傳 GitHub，並說明之後如何依規則延伸。

## AI 協助的部分
Codex 協助選擇「失物記憶所」主題，撰寫 AGENTS.md、內容資料格式、網站程式、四篇虛構故事、本地 SVG 插圖、測試、文件及部署。未使用真實私人對話或 API 金鑰；本專案不需要 LLM API。

## 理解用說明（AI 撰寫，請學生閱讀確認）
AGENTS.md 是給 AI 的開發規則，不是執行時的提示詞；網站不需要持續呼叫 AI。JSON 保存內容，產生器負責將相同欄位套入共用 HTML 版型，CSS 控制共同外觀。規則中的限制由 validate() 檢查，新增故事會自動更新列表與導覽。

## 延伸指令範例（建議用法，非冒充使用者曾輸入）
「閱讀 AGENTS.md 與 templates/story.json，新增 borrowed-umbrella 故事，主題為借傘形成的友誼。保持原本視覺與版型，執行驗證、建置和延伸測試。」

## 實際產出
第四篇 borrowed-umbrella 與前三篇使用相同 JSON 結構。測試程式會分別建置三篇與四篇版本，驗證新增故事頁、首頁連結以及第三篇的下一篇連結。實際檢查結果另記錄在 CHANGELOG，不以模擬測試宣稱真人理解或第二位獨立 AI 的表現。
